# The_greatest_parser
Парсер трёх маркетплейсов (WB, Ozon, Яндекс Маркет)



Собирает данные о товарах с трёх маркетплейсов, сохраняет в базы данных SQLite и ведёт логи.


Что умеет



- Парсинг Wildberries — название, цена, ссылка

- Парсинг Ozon — название, цена, ссылка

- Парсинг Яндекс Маркета — название, цена, ссылка

- Сохранение в отдельные БД — `Wildberries.db`, `Ozon.db`, `Yandex.db`

- Просмотр БД — посмотреть все сохранённые товары

 > Если БД очень большая, для просмотра используй DB Browser for SQLite

- Очистка БД — удалить все записи из выбранной таблицы

- Логирование — все действия пишутся в `parser.log`

- Просмотр и очистка логов — прямо из меню



 Технологии



- Python 3.10+

- Playwright (обход защиты)

- SQLite (встроен в Python)

- logging



Как пользоваться



1. Установи Playwright:

  

  pip install playwright

  playwright install
